PowerWidget — Mac 桌面功耗小组件
=====================================

【三步安装】

⚠️ 重要:解压后,**请把整个 PowerWidget 文件夹拖到「桌面」或「下载」**,
然后再进行下面操作。直接在 zip 内双击会被 macOS 安全机制拦住。

1. 解压后,你会看到这些文件:
     • PowerWidget.app    主程序
     • install.command    一键安装(双击)
     • uninstall.command  一键卸载(双击)
     • 使用说明.txt        本文件

2. **「右键」点击 install.command → 选「打开」**
   不会右键?三选一(都行):
   - 按住键盘 Control 键,再用一个手指点击 install.command,选「打开」
   - 触控板上用两根手指同时点击 install.command,选「打开」
   - 鼠标右键直接点击 install.command,选「打开」

   然后会弹出"无法验证开发者?"对话框 → 点「打开」
   (这是 macOS 的安全提示,只第一次会问)

3. **弹出 macOS 密码框 → 输入你的 Mac 登录密码 → 完成!**
   - 这是给后台采集服务授权,只输这一次
   - 之后开机自动启动,不会再问

桌面右上角应该出现深色半透明小组件。如果看不到 → 按 F11(或触控板四指张开 = 显示桌面)。


【小组件每一块的意思】

┌─────────────────────────────────────────┐
│        散热压力: 较热(↑顶部,颜色变)    │
│                                         │
│  ⭕97%      芯片 0.8 W                  │
│  电量      整机 14.5 W                  │
│                                         │
│  应用耗电指数(越大越耗电)              │
│  Claude          25 (红=高/橙=中/灰=低) │
│  访达             7                     │
│  Chrome           3                     │
└─────────────────────────────────────────┘

- 顶部「散热压力」:macOS 算的 SoC 降频压力等级(不是温度数字),正常/微热/偏热/较热/严重发热
- 圆环 + 百分比:电池电量(跟 Mac 状态栏一致)
- 大字「芯片 X.X W」:CPU+GPU 实时功耗(1Hz 刷新)
- 小字「整机/电池 X.X W」:
   * 拔电源时 = 整机功耗(含屏幕)
   * 充电时 = 充入电池的速率
   * 满电或暂停充电时显示状态文字
- 底部 Top 3 应用:macOS 算的能耗指数,数值不带单位,数字越大越耗电
  系统进程、守护进程不显示,只显示 Dock 里有图标的应用


【日常使用】

- 鼠标按住小组件 → 拖动到喜欢的位置(自动记住)
- 双击小组件 → 关闭
- 想再次打开 → 直接双击 PowerWidget.app
- 重启 Mac 后:自动启动,不需要再做任何事


【⚠️ 移动 .app 后必读】

如果你以后想把 PowerWidget.app 移到「应用程序」文件夹或其他位置,
移动后请**再双击一次 install.command**(在新位置/旁边的那个)。
否则下次开机自启会找不到 .app,widget 不显示。


【⚠️ 卸载请用 uninstall.command】

不要只把 .app 拖到废纸篓 — 那样后台服务还在跑,会持续占用 CPU 和磁盘。
正确卸载:双击 uninstall.command → 输 Mac 密码 → 之后再把 .app 拖到废纸篓。


【系统要求】

- Apple Silicon Mac(M1 / M2 / M3 / M4)
- macOS 11(Big Sur)或更新版本
- 不支持 Intel Mac


【卸载】

双击 uninstall.command → 输 Mac 密码 → 完成。然后把 PowerWidget.app 拖到废纸篓。

不要直接拖废纸篓!那样后台服务会留下,持续占用资源。


【常见问题】

Q: 小组件不显示数字,一直"等数据"?
A: 安装时密码框可能没正确处理。双击 uninstall.command 卸载,然后重新双击 install.command 安装一次。

Q: 看不到小组件?
A: 它在「桌面图标层」,会被打开的窗口挡住。按 F11(或触控板四指张开)显示桌面。

Q: 想看日志?
A: 在终端运行:cat ~/Library/Logs/PowerWidget.log

Q: 电脑摸着烫,但「散热压力」显示"正常"?
A: 它不是温度数字,是 macOS 算的「SoC 是否需要降频」的等级。
   Apple Silicon 设计是让 SoC 跑到 90°C+ 才开始降频,所以你壳子烫但
   SoC 没到降频阈值,系统就报"正常"。
   想看具体 °C 温度,Apple 没公开这数据(只有 Stats 等用私有 API 的工具能读)。
